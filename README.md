# ビジネス開脳コミュニティ LP — 編集ガイド

## このフォルダの中身

- `index.html` — ページ本体(HTML + CSS + JavaScriptが1つにまとまっています)
- `images/` — 画像と動画
- `README.md` — このファイル

## 動作確認のしかた

`index.html` をダブルクリックでブラウザに表示できます(Chrome / Edge / Safari いずれもOK)。動画や画像はこのフォルダ構成のまま動きます。

## よくある編集ポイント

### 1. テキストの修正

`index.html` をテキストエディタ(Visual Studio Code 推奨)で開き、
書き換えたい文字を直接修正 → 保存。ブラウザを再読込みして反映を確認してください。

ファイル内で大きなセクションは以下のコメントで区切られています:

```
<!-- About -->
<!-- Courses -->
<!-- GENSEN -->
<!-- Growth -->
<!-- Schedule -->
<!-- FAQ -->
<!-- Pricing -->
<!-- Profile -->
```

### 2. 画像の差し替え

`images/` フォルダ内の対応するファイルを **同じファイル名で上書き** すれば差し替わります。

主な画像:

| ファイル名 | 用途 |
|---|---|
| `Brain_FV.mp4` | FV(ファーストビュー)の背景動画 |
| `Brain_FV_poster.jpg` | 動画ロード前に表示される静止画 |
| `lady_fv.png` | FVに登場する女性(背景透過 PNG) |
| `man_fv.png` | FVに登場するヘルメット男性 |
| `main_fv_mask.png` | FVのメイン男性(中央) |
| `0_Futuristic_Data.mp4` | 全体の背景動画 |
| `571327.jpg` | 「得られる成長」セクションの背景画像 |
| `yamamoto-san.jpg` | プロフィール写真 |

### 3. 申し込みリンクの差し替え

`index.html` 内の以下のリンクが申し込みURLです。差し替えたい場合は `href="..."` の URL を書き換えてください。

```html
<a href="https://utage-system.com/p/OFxxUfw4fRpr" class="btn-cyber" style="margin-top:20px">今すぐ申し込む</a>
```

なお、ナビバーや FV / 最終CTA の「今すぐ申し込む」ボタンは内部の `#pricing` セクションへスクロールする仕組みなので変更不要です。

### 4. 配色

ファイル先頭の `<style>` ブロック内で次のように定義されています(変更すると全体に反映):

```
:root{
  --gold:#d4af37;       /* メインのゴールド */
  --gold-light:#f4d77a; /* ハイライト */
  --gold-dark:#8a6d1b;  /* 影色 */
  --bg:#050505;         /* 背景の黒 */
}
```

## 公開のしかた

1. レンタルサーバーやレジストラ管理画面の FTP / アップロード機能でこのフォルダ全体をアップロード
2. もしくは Vercel / Netlify / Cloudflare Pages などの静的ホスティングで「フォルダをドラッグ & ドロップ」するだけでも公開できます
3. 独自ドメインは利用するホスティング側で設定してください
